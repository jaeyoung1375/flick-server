# 프로젝트 정체성 (jobmoa-server Overview)

이 문서는 AI 작업용 사실 정리입니다. 프로젝트의 주관적 목적·우선순위는 [`guide.md`](./guide.md)에 사용자가 직접 적습니다.

## 1. 정체성

**jobmoa**는 여러 채용사이트의 공고를 한곳에 모아 볼 수 있게 하는 채용정보 통합(잡 어그리게이터) 서비스다. `jobmoa-server`는 그 백엔드 API 서버가 될 예정이다(프로젝트 목적·배경은 [`guide.md`](./guide.md) 참고).

> ⚠️ **레거시 코드베이스:** 이 저장소는 개인 운동 기록 서비스 `motive-server`를 복제한 초기 스캐폴딩이며, 아래 "2. 제공 기능"은 **현재 코드에 남아있는 motive-server 시절 기능을 그대로 실측한 것**이다. 채용정보 도메인 기능은 아직 구현되지 않았다. 인증·3계층 구조·공통 응답 등 기술 골격은 그대로 재사용 가능하지만, `admin/exercise`·`fitness`·`workout`·`recommend`·`aichat`(운동 추천) 도메인 패키지는 채용정보 도메인으로 교체되기 전까지의 임시 상태다.

| 항목          | 내용                                                           |
| ------------- | -------------------------------------------------------------- |
| 패키지 루트   | `kr.co.jobmoa`                                                 |
| 그룹/버전     | `kr.co.jobmoa` / `0.0.1-SNAPSHOT` (build.gradle)               |

| 활성 프로파일 | `local` (기본), `dev` 존재. `secret` 프로파일을 항상 `include` |

## 2. 제공 기능 (컨트롤러 기준 실측)

- **인증/온보딩** — 소셜 로그인(카카오/구글/깃허브) → JWT 발급, 액세스 토큰 재발급, 내 정보 조회
- **운동 프로필** — 경력·레벨·보유장비·신체정보 등록/조회/수정 (최초 등록 여부 = 온보딩 완료 여부 판정 기준)
- **운동 기록** — 날짜별 운동 기록(헤더) + 기록에 속한 운동들(상세) + 운동별 세트(중량/횟수) CRUD
- **운동 마스터** — 운동 목록/상세 공개 조회, 관리자 CRUD
- **공통코드** — 공개 조회(2종), 관리자 CRUD(공통코드+상세코드)
- **메뉴** — 전체 메뉴 조회 (공개)
- **파일** — 에디터 이미지 업로드 (로컬 디스크 `C:/upload`)

## 3. 이것과 다른 저장소의 관계

- jobmoa의 프론트엔드는 아직 정해지지 않았다. 현재 `CorsConfig`가 허용하는 오리진(`http://localhost:3000` 등)은 motive-server 시절 프론트엔드(`motive-ui`, Next.js) 개발 포트가 그대로 남아있는 것이며, jobmoa 자체 프론트엔드가 정해지면 갱신이 필요하다.

## 4. 워크플로우 요약

```
소셜 로그인(OAuth2) → JWT 발급(Access 30분/Refresh 14일, Redis 저장)
    → (최초) 운동 프로필 온보딩 → 운동 기록 등록/조회/수정/삭제
```

- 온보딩 완료 여부는 `/auth/refresh` 응답의 `onboardingCompleted` 필드로 프론트에 전달된다(`FitnessProfileMapper.existsProfile`).
